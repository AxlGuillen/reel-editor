# assets/competitivo

Archivos opcionales de la intro y la portada del módulo `competitivo`. Si no están, el módulo funciona igual.

- `fondo_portada.png`: fondo de la portada y de la placa de la intro. Se escala y se recorta al tamaño de cada una, con un velo oscuro leve para que el texto se lea. Sin este archivo se usa un degradado oscuro.
- `sting.mp3`: suena al 35 % debajo de la voz de la intro. Si el archivo no está, no hay sting.
