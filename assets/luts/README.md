# LUTs (.cube)

Gradaciones de color para los edits (`lut` en anime_edit y en el modo edit de
competitivo). Se aplican con `lut3d` antes del look elegido.

- Formato: `.cube` 3D (el que exportan DaVinci Resolve, Photoshop o Lightroom).
- Solo LUTs **propias o con licencia que permita uso comercial**: el repo se
  copia entre máquinas y los videos se publican.
- Sin LUT, los looks de código (`dorado`, `cine`, `frio`, `noche`, `fuego`,
  `vivo`) cubren lo de siempre; están en `modules/edicion/efectos.py`.
