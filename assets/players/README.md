# assets/players

Fotos de los jugadores para las **tarjetas de jugador** del módulo `competitivo` (`cards=Canyon,Rookie` en `/finish`).

- Un archivo por jugador, con su nombre de invocador: `Canyon.png`, `Rookie.jpg`. No importan las mayúsculas ni las tildes
  (`josedeodo.png` sirve para «Josedeodo»). Formatos: png, jpg, jpeg, webp.
- Mejor retratos verticales (la tarjeta los recorta a 300x290 desde arriba, para que la cara quede a la vista).
- Si no hay foto, la tarjeta lleva una silueta con las iniciales del jugador: funciona igual.
- Es contenido de Axl: se versiona con el resto de `assets/`.
